# Amazon S3 (Simple Storage Service)

> Curso: AWS Certified Data Engineer – Associate (DEA-C01)

## ¿Qué es S3?

S3 es uno de los **principales bloques de construcción de AWS** y la solución de **almacenamiento de objetos** por excelencia: rentable, sencilla y muy usada en prácticamente cualquier cuenta de AWS.

### Conceptos base

| Concepto            | Descripción                                     |
| ------------------- | ----------------------------------------------- |
| **Bucket (cubo)**   | Contenedor de archivos.                         |
| **Object (objeto)** | El archivo real almacenado dentro de un bucket. |

- Los buckets pueden organizarse mediante una **estructura de carpetas** (aunque en realidad, a nivel interno, S3 es un almacenamiento plano de objetos).
- Los archivos se pueden subir directamente al bucket o dentro de esa estructura de carpetas.

## Buckets: región y nomenclatura

### Región

- Cada bucket se crea en una **región específica**, donde también se almacenan **físicamente** los datos (en los centros de datos de AWS de esa región).
- La elección de región importa por:
  - **Latencia:** conviene ubicar los datos cerca de donde se accede a ellos (aplicación o usuarios).
  - **Cumplimiento normativo (compliance):** distintas regiones pueden tener normativas distintas.

### Nombre único global

- El nombre de un bucket debe ser **único a nivel global**: no puede repetirse entre regiones ni entre cuentas distintas de AWS.

### Reglas de nomenclatura

- Entre **3 y 63 caracteres**.
- Solo **letras minúsculas, números, puntos (.) y guiones (-)**.
- Debe **empezar y terminar** con una letra o número.
- **No puede tener forma de dirección IP** (ej. `192.168.1.1`).

## El concepto de Key (clave)

La **key** es lo que identifica de forma única a un objeto **dentro de un bucket**.

- Ejemplo simple: si se sube `ejemplo.txt` directamente al bucket (sin carpetas), la key es `ejemplo.txt`.
- Ejemplo con carpetas: si se sube `ejemplo.txt` dentro de una carpeta `documentos/`, la key sería `documentos/ejemplo.txt`.

> ⚠️ La key **no incluye el nombre del bucket** — es la ruta completa **dentro** del bucket (carpeta(s) + nombre de archivo).

## Casos de uso típicos

- **Copias de seguridad y recuperación** (backup & recovery)
- **Alojamiento de sitios web**
- **Almacenamiento para aplicaciones**
- **Archivado de datos**
- **Data lakes** (lagos de datos) para fines analíticos
- Almacenamiento de datos **estructurados, semi-estructurados (ej. CSV) y no estructurados** (ej. PDFs)
- Consulta directa de esos datos mediante **Amazon Athena** (se verá más adelante)

## Clases de almacenamiento (introducción)

Existen distintas **clases de almacenamiento** en S3, pensadas para diferentes casos de uso, con características distintas en cuanto a **disponibilidad** (no así en durabilidad, que es constante entre clases). Se profundizará más adelante, pero como introducción:

### Durabilidad

- La durabilidad de S3 es de **11 nueves (99.999999999%)**, independientemente de la clase de almacenamiento.
- Esto representa la **probabilidad de perder un objeto en un año determinado**.
- En la práctica: se esperaría perder **1 de cada 100.000.000 de objetos** en un año — una probabilidad extremadamente baja.

### Disponibilidad

- Es el **porcentaje de tiempo en que el servicio está operativo** y los datos son accesibles.
- A diferencia de la durabilidad, la disponibilidad **sí varía** según la clase de almacenamiento elegida.

## Reglas de ciclo de vida (Lifecycle Rules)

Permiten cambiar automáticamente la clase de almacenamiento de un archivo, carpeta o bucket completo en función de su **antigüedad**.

### Ejemplo

- Primeros 30 días → acceso frecuente → clase **S3 Standard**.
- Después de 30 días → se archiva automáticamente → clase de almacenamiento más económica.

## Versionado (Versioning)

- Permite acceder a **versiones anteriores** de un archivo.
- Protege ante **modificaciones o borrados accidentales**, manteniendo versiones previas disponibles.
- Es una **capa adicional de seguridad** que se puede habilitar en un bucket.
