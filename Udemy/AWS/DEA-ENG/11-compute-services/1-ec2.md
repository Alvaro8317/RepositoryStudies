# EC2 (Elastic Compute Cloud)

> Curso: AWS Certified Data Engineer – Associate (DEA-C01)

## ¿Qué es EC2?

EC2 es uno de los servicios más fundacionales y populares de AWS: nos proporciona **potencia de
cálculo** en forma de servidores virtuales, llamados **instancias**, que podemos configurar, lanzar
y gestionar fácilmente.

Ofrece **capacidad informática segura y redimensionable en la nube**, escalable bajo demanda.

> ⚠️ Muchos otros servicios de AWS usan EC2 "bajo el capó":
>
> - **RDS** (base de datos relacional) se ejecuta sobre instancias EC2.
> - **ECS** y **EKS** (contenedores) también ejecutan sus contenedores sobre EC2, aunque también se
>   puede usar **AWS Fargate** para cómputo serverless.
> - **AWS Lambda**, aunque es cómputo serverless (no gestionamos servidores), en realidad también se
>   ejecuta sobre infraestructura de cómputo que puede considerarse una capa abstracta por encima
>   de EC2.

## Configuración de una instancia

Cada instancia se configura combinando:

- **CPU**
- **Memoria**
- **Almacenamiento**
- **Red**

Podemos elegir configuraciones predefinidas (tipos de instancia) o ajustar estos recursos nosotros
mismos según las necesidades específicas de la carga de trabajo. También tenemos control total
sobre el sistema operativo, la configuración de red, las opciones de almacenamiento y la seguridad.

## Alta disponibilidad y escalado

- Las instancias EC2 se distribuyen en varias **zonas de disponibilidad** dentro de una región de
  AWS, lo que proporciona alta disponibilidad y tolerancia a fallos.
- Los usuarios pueden desplegar aplicaciones en varias zonas de disponibilidad para reforzar esa
  resiliencia.
- **Autoescalado**: permite ajustar automáticamente el número de instancias en respuesta a cambios
  en la carga de trabajo.
- Se integra de forma nativa con otros servicios como **IAM**, **S3**, **CloudWatch**, etc.

## Tipos de instancia

EC2 ofrece varios tipos de instancia, cada uno con una combinación distinta de CPU, memoria,
almacenamiento y red, optimizada para cargas de trabajo específicas.

| Tipo                                 | Optimizado para                                                                       | Casos de uso típicos                                                                                                                                                                                      |
| ------------------------------------ | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Propósito general**                | Equilibrio entre cómputo, memoria y red                                               | Servidores web, repositorios de código, aplicaciones que usan los recursos en proporciones similares                                                                                                      |
| **Optimizadas para cómputo**         | Procesadores de alto rendimiento                                                      | Procesamiento por lotes, transcodificación de medios, servidores web de alto rendimiento, HPC, modelado científico, servidores de juegos dedicados, motores de ad-serving, inferencia de machine learning |
| **Optimizadas para memoria**         | Rendimiento rápido para cargas que procesan grandes volúmenes de datos en memoria     | Workloads intensivos en memoria                                                                                                                                                                           |
| **Cómputo acelerado**                | Aceleración por hardware (hardware especializado en vez de CPUs de propósito general) | Cálculo de números en coma flotante, procesamiento gráfico, pattern matching de datos                                                                                                                     |
| **Optimizadas para almacenamiento**  | Acceso de lectura/escritura secuencial y de alto rendimiento a almacenamiento local   | Conjuntos de datos muy grandes con I/O intensivo                                                                                                                                                          |
| **HPC (High Performance Computing)** | Clusters de procesadores potentes trabajando en paralelo                              | Procesamiento de big data, simulaciones grandes y complejas, cargas de deep learning                                                                                                                      |

> ⚠️ **HPC** (High Performance Computing / computación de alto rendimiento) usa clusters de
> procesadores potentes que trabajan en paralelo para procesar conjuntos masivos de datos
> multidimensionales (big data) y resolver problemas complejos a velocidades muy altas.
