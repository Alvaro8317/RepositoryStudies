# Exam Overview

> Curso: Claude Certified Developer - Foundations (CCDV-F)-Exam Prep

## Introducción

La certificación está pensada para personas que **construyen con Claude**, así que el curso se
concentra en la API, el Agent SDK, las tools y MCP. Esta primera clase explica qué evalúa el
examen, para quién es el curso y cómo aprovecharlo.

## 1. Formato del examen

| Aspecto           | Detalle                                        |
| ----------------- | ---------------------------------------------- |
| Preguntas         | 53                                             |
| Duración          | 2 horas                                        |
| Puntaje aprobador | Scaled score de **720 / 1000**                 |
| Modalidad         | Proctored: online o en un centro de evaluación |
| Costo             | USD 125                                        |
| Vigencia          | **12 meses**, luego expira                     |

## 2. Los ocho domains y su peso

El peso de los domains está **muy desbalanceado**, y conviene tenerlo claro desde el inicio:

| Domain                         | Peso | Preguntas aprox. (de 53) |
| ------------------------------ | ---- | ------------------------ |
| Applications and Integration   | ~33% | ~17                      |
| Model Selection                | 17%  | ~9                       |
| Agents and Workflows           | 15%  | ~8                       |
| Prompt and Context Engineering | 11%  | ~6                       |
| Tools and MCP                  | 11%  | ~6                       |
| Security                       | 8%   | ~4                       |
| Claude Code                    | 3%   | ~1-2                     |
| Evaluation                     | 3%   | ~1-2                     |

> 🎯 Solo **Applications and Integration** vale un tercio del examen, y junto con Model Selection
> y Agents and Workflows suma casi dos tercios. Claude Code y Evaluation pesan muy poco en esta
> certificación.

> ⚠️ La columna de preguntas aproximadas es una estimación propia (peso × 53), no un dato oficial.

## 3. Perfil esperado y a quién va dirigido el curso

Anthropic espera que el candidato tenga:

- **1 a 5 años** de experiencia en ingeniería de software.
- **6 meses** construyendo con Claude.

Es un requisito exigente, y el examen se vuelve bastante difícil si no se cumple.

El curso **asume que ya usas Claude en trabajo real**:

- No cubre el setup ni la configuración.
- No ejecuta código en pantalla.
- Cuando muestra un ejemplo, asume que puedes reconstruirlo por tu cuenta en tu entorno.

> ⚠️ Si todavía no tienes esas horas de práctica, este no es el punto de partida: conviene tomar
> primero un curso más básico, acumular experiencia práctica y volver después.

## 4. Vigencia y renovación

La credencial es válida por **12 meses** y luego expira. No es una trampa, sino una forma de
responder a un objetivo que cambia rápido: Claude evoluciona tanto que una credencial de cinco
años terminaría certificando conocimiento sobre una versión de Claude que ya nadie usa.

Cuando se abre la ventana de renovación:

1. Repasas lo que cambió desde que te certificaste.
2. Completas un **assessment gratuito y no proctored** en el sitio de **Anthropic Partner Academy**.

Si renuevas a tiempo, **no tiene costo**. Lo que obtienes es una declaración actualizada de lo
que sabes hoy.

## 5. Cómo usar el curso

| Situación                   | Estrategia                                                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Te preparas por primera vez | Ver las lecciones **en orden** (se construyen una sobre otra) y luego hacer practice exams hasta superar con holgura el 720 |
| Vuelves a renovar           | No hace falta ver todo: empezar por las lecciones actualizadas y hacer practice questions nuevas para confirmar tu criterio |

En ambos casos, los **practice exams son la herramienta de calibración**.

### Material de estudio complementario (study pack)

El curso incluye un study pack gratuito que se descarga desde el último video del curso. Trae:

- Un *study companion* que condensa todo el curso en un documento.
- Un plan de estudio de **30 días** con las lecciones exactas para cada día.
- Tres mini-exámenes de **30 preguntas** cada uno, con explicaciones completas.
- Un glosario de key terms, flashcards imprimibles y todas las diapositivas del curso.

> 📌 El instructor recomienda descargarlo **antes** de empezar las lecciones.

## 6. El consejo principal: patrones, no firmas

**Aprende los patrones, no las firmas.** Los nombres, los parámetros y los límites cambian; el
razonamiento detrás de una buena decisión de diseño se mantiene, y eso es lo que el examen evalúa
de verdad.

> 💡 A lo largo del curso, el instructor va a señalar qué contenido es **estable** y cuál es
> **volátil**, para que sepas dónde vale la pena invertir tu tiempo de estudio.

## Puntos clave

1. 53 preguntas, 2 horas, 720/1000 para aprobar, USD 125, proctored.
2. Applications and Integration vale un tercio del examen; Claude Code y Evaluation apenas 3% cada uno.
3. Perfil esperado: 1-5 años de ingeniería de software + 6 meses construyendo con Claude.
4. La credencial dura 12 meses; la renovación a tiempo es gratuita y no proctored (Anthropic
   Partner Academy).
5. Estudia el razonamiento de diseño (patrones), no los nombres de parámetros o límites (firmas).
