# Creation Actions: panorama general

> Curso: Midjourney (Udemy)

## Qué son

Al generar una imagen en la web de Midjourney (v6 o v7), debajo de cada resultado aparece un panel de
opciones agrupadas bajo el título **Creation Actions** (acciones de creación). Permiten trabajar
directamente sobre la imagen generada: explorar nuevas versiones, mejorar la calidad, cambiar estilos,
o reutilizar prompts e imágenes previas.

> ⚠️ Para ver este panel es necesario primero **hacer clic sobre la imagen y maximizarla**. No aparece
> en la vista de miniaturas (grid) donde se muestran las 4 imágenes generadas.

Esta lección es un panorama introductorio; cada acción se explicará en detalle con ejemplos prácticos
en lecciones posteriores.

## Vary (variaciones)

Genera imágenes similares a la actual, pero con cambios.

| Opción     | Comportamiento                                                               |
| ---------- | ---------------------------------------------------------------------------- |
| **Subtle** | Nuevas imágenes con pequeñas diferencias respecto a la original              |
| **Strong** | Nuevas imágenes con cambios más notorios y creativos, conservando la esencia |

## Upscale (escalado)

Crea versiones más grandes y en más alta resolución de la imagen, ideal para compartir, guardar o
imprimir.

| Opción       | Comportamiento                                                                     |
| ------------ | ---------------------------------------------------------------------------------- |
| **Subtle**   | Agranda la imagen sin cambios en el contenido                                      |
| **Creative** | Agranda la imagen, pero puede añadir más detalle y algunos cambios en el contenido |

## Rerun

Vuelve a generar una imagen nueva basada en el mismo prompt (sin abrir el editor).

## Edit

Abre la imagen para edición: permite cambiar parte del prompt o ajustar configuraciones sin tener que
volver a escribir todo desde cero.

## Use (reutilizar)

| Opción     | Comportamiento                                                       |
| ---------- | -------------------------------------------------------------------- |
| **Image**  | Reutiliza la imagen actual como referencia visual en un nuevo prompt |
| **Style**  | Copia el estilo visual de la imagen y lo aplica a una nueva creación |
| **Prompt** | Recupera el prompt original (texto) para ajustarlo antes de reenviar |

## Por qué importa este panel

Dominar las Creation Actions permite:

- Generar variaciones controladas o creativas de una imagen.
- Decidir cuándo y por qué hacer upscale (subtle vs. creative).
- Rehacer o editar imágenes sin comenzar desde cero.
- Aprovechar creaciones propias como plantillas de estilo o composición.

Es una de las herramientas más potentes de la plataforma para trabajar de forma iterativa, profesional
y eficiente dentro del flujo de Midjourney.
